# Hangman Word Guessing Game

## About the Project

This is a console-based Hangman game developed using Python. The player must guess a randomly selected hidden word one letter at a time.

## Features

- Random word selection
- Six incorrect attempts allowed
- Displays hidden letters using underscores
- Checks correct and incorrect guesses
- Prevents duplicate guesses
- Validates user input
- Displays ASCII Hangman stages
- Shows winning and losing messages

## Technologies Used

- Python 3
- random module

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code or a terminal.
4. Run:

```bash
python hangman.py
```
